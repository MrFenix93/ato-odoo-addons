Date Format Fix

Consistent date and datetime formatting across Odoo 20 backend views.

Overview

Date Format Fix is a lightweight enhancement for Odoo 20 that provides a consistent date and datetime display format throughout supported backend views.

The module presents dates in DD/MM/YYYY format and datetime values in DD/MM/YYYY HH:mm:ss format, improving readability and consistency.
