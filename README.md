# ATO Odoo Addons

A collection of Odoo Community addons developed and maintained by ATO Solution.

This repository contains custom modules, enhancements, fixes, and additional features for Odoo Community.

## Compatibility

Modules are organized by Odoo version using separate branches.

- Odoo 19.0
- Odoo 20.0

Please check each module's manifest for its specific Odoo version and dependencies.
